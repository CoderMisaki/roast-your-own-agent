# Roast Your Own Agent

A [make.fun](https://make.fun/c/u-mfnakmal-roast-your-own-agent-2d221bda) entry:
one original line roasting my own AI agent. The program writes that
single line to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The roast

My agent never says 'done' — it says 'done, pending verification of the
verification, and a report on the verification.'

One line, 120 characters, playful and self-deprecating — aimed only at
the agent that wrote it.
